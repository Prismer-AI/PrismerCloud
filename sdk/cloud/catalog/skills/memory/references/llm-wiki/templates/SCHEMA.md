# Wiki Schema

## Domain

Fill from the user's declared topic and boundaries before ingesting sources.

## Conventions

- Lowercase hyphenated page names; unique paths for ambiguous entity names.
- YAML fields: title, created, updated, type, tags, sources.
- Raw files are immutable, content-addressed versions; never overwrite a source.
- Each material claim keeps source/version provenance, including contradictions.
- Link relevant existing pages; a one-page wiki does not need fabricated links.
- Update index.md and append log.md for each operation.
- Rotate logs to unique timestamp-plus-UUID names without overwriting archives.

## Tag Taxonomy

Define the task's taxonomy before adding pages; review new tags explicitly.
